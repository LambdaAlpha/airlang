# 映射

## .map.get_length

类型：function

上下文：不变

输入：无关

ctx 应为映射，输出 ctx 的长度。

## .map.get_items

类型：function

上下文：不变

输入：无关

ctx 应为映射，输出 ctx 的键值对的列表。

## .map.into_items

类型：function

上下文：可变

输入：无关

ctx 应为映射，移除并输出 ctx 的键值对的列表。

## .map.get_keys

类型：function

上下文：不变

输入：无关

ctx 应为映射，输出 ctx 的键的列表。

## .map.into_keys

类型：function

上下文：可变

输入：无关

ctx 应为映射，移除并输出 ctx 的键的列表。

## .map.get_values

类型：function

上下文：不变

输入：无关

ctx 应为映射，输出 ctx 的值的列表。

## .map.into_values

类型：function

上下文：可变

输入：无关

ctx 应为映射，移除并输出 ctx 的值的列表。

## .map.contain

类型：function

上下文：不变

input 应为键，ctx 应为映射，输出 ctx 是否包含 input。

## .map.contain_all

类型：function

上下文：不变

input 应为列表，ctx 应为映射，输出 ctx 是否包含 input 中的所有键。

## .map.contain_any

类型：function

上下文：不变

input 应为列表，ctx 应为映射，输出 ctx 是否包含 input 中的任意键。

## .map.set

类型：function

上下文：可变

input 应为 `k : v`，ctx 应为映射，将 ctx 中键 `k` 所绑定的值设为 `v`，并输出其原来绑定的值的单元格。

## .map.set_many

类型：function

上下文：可变

input 应为映射，ctx 应为映射，将 input 中的键值对设置到 ctx 中，并输出这些键在 ctx 中原来绑定的值的映射。

## .map.get

类型：function

上下文：不变

input 应为键，ctx 应为映射，输出 ctx 中 input 所绑定的值的单元格。

## .map.get_many

类型：function

上下文：不变

input 应为键列表，ctx 应为映射，输出 input 中的键在 ctx 中所绑定的值的映射。

## .map.remove

类型：function

上下文：可变

input 应为键，ctx 应为映射，移除并输出 ctx 中 input 所绑定的值的单元格。

## .map.remove_many

类型：function

上下文：可变

input 应为键列表，ctx 应为映射，移除并输出 input 中的键在 ctx 中所绑定的值的映射。

## .map.clear

类型：function

上下文：可变

输入：无关

ctx 应为映射，清空 ctx。

## .map.make

类型：function

上下文：无关

input 应为键值对列表，从 input 构建一个映射。

## .map.make_set

类型：function

上下文：无关

input 应为键列表，从 input 构建一个映射，所有键绑定的值都是单元。
