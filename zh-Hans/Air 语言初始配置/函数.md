# 函数

## .function.make

类型：function

上下文：无关

构造一个函数。

input 应为映射

- code：调用过程的表示，`(ctx : input) : body`，`ctx` 为上下文变量名或单元，`input` 为输入变量名或单元，`body` 为函数体
- prelude：初始上下文
- constant: 是否上下文不变

## .function.represent

类型：function

上下文：无关

表示一个函数。输出一个映射

- code：调用过程的表示，`(ctx : input) : body`，`ctx` 为上下文变量名，`input` 为输入变量名，`body` 为函数体
- prelude：初始上下文
- constant: 是否上下文不变

## .function.is_free

类型：function

上下文：无关

输入：无关

input 应为函数，输出 input 是否上下文无关。

## .function.is_constant

类型：function

上下文：无关

输入：无关

input 应为函数，输出 input 是否上下文不变，若为默认，则输出单元。

## .function.is_input_free

类型：function

上下文：无关

输入：无关

input 应为函数，输出 input 是否输入无关。

## .function.is_primitive

类型：function

上下文：无关

输入：无关

input 应为函数，输出 input 是否为基础函数。

## .function.get_code

类型：function

上下文：无关

输入：无关

input 应为函数，输出 input 的代码的表示。

## .function.get_prelude

类型：function

上下文：无关

输入：无关

input 应为函数，输出 input 的初始上下文。

## .function.get_id

类型：function

上下文：无关

输入：无关

input 应为函数，输出 input 的 id。函数相等等价于其 id 相等。
