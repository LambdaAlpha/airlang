## .context.get

类型：function

上下文：不变

输出 input 所绑定的值。

## .context.take

类型：function

上下文：可变

输出 input 所绑定的值，设置 input 绑定单元。

## .context.set

类型：function

上下文：可变

input 应为 `key : value`，设置 `key` 绑定 `value`。

## .context.is_constant

类型：function

返回上下文是否不变。

## .context.is

类型：function

上下文：可变

模式匹配与赋值。仅匹配一个模式，若匹配成功，则执行绑定。

### 匹配绑定

匹配绑定 `bind` 与 `value` 的过程：

- 若 `pattern` 为键 `_a`，`a` 为任意键，则匹配 `a`
- 若 `pattern` 为键 `''`，则匹配任意值，不绑定
- 若 `pattern` 为键 `a`，则匹配任意值 `v`，将 `v` 绑定到 `a`
- 若 `pattern` 为字面量 `v`，则匹配 `v`
- 若 `pattern` 为 `.(b)`（`_(b)`），则匹配 `.(v)`（`_(v)`），递归将 `v` 与 `b` 匹配绑定
- 若 `pattern` 为 `b1 : b2`（`_ b1 b2`，`? b1 b2`），则匹配 `v1 : v2`（`_ v1 v2`，`? v1 v2`），递归
  - 将 `v1` 与 `b1` 匹配绑定
  - 将 `v2` 与 `b2` 匹配绑定
- 若 `pattern` 为 `[b1, b2, ..., bn]`，则匹配列表 `l`，递归
  - 将 `l` 的第一个值与 `b1` 匹配绑定
  - 将 `l` 的第二个值与 `b2` 匹配绑定
  - ...
  - 将 `l` 的第 `n` 个值与 `bn` 匹配绑定
- 若 `pattern` 为 `{k1 : b1, k2 : b2, ..., kn : bn}`，则匹配映射 `m`，递归
  - 将 `m` 中 `k1` 所绑定的值与 `b1` 匹配绑定
  - 将 `m` 中 `k2` 所绑定的值与 `b2` 匹配绑定
  - ...
  - 将 `m` 中 `kn` 所绑定的值与 `bn` 匹配绑定

## .context.get_self

类型：function

上下文：不变

输入：无关

## .context.let

类型：function

input 应为 `c : f : i`，在 ctx 中以键 c 为键，得到上下文 c1，以 c1 为上下文，以 i 为输入调用 f。

## .context.let.bind

类型：function

上下文：无关

input 应为函数，输出一个函数 `g`，使得 `ctx g input` 等价于 `ctx context.let g : input`。

大多数上下文读写函数都导出了绑定函数，绑定函数的键为原函数的键 + `.context.let`。
