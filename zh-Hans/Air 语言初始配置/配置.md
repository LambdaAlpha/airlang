# 配置

## .config.exist

类型：function

上下文：无关

input 应为键，判断 cfg 中是否存在 input。

## .config.import

类型：function

上下文：无关

input 应为键，导入 cfg 中 input 的值。

## .config.export

类型：function

上下文：无关

input 应为 `key : value`，以 key 为键导出 value 到 cfg。

## .config.get_length

类型：function

上下文：无关

输入：无关

获取 cfg 的长度。

## .config.with

类型：function

input 应为 `map : body`，用 map 中的键值对覆盖 cfg，执行 body，得到 o，恢复 cfg，返回 o。

## .config.get_self

类型：function

上下文：无关

输入：无关

获取 cfg。

## .config.let

类型：function

上下文：可变

input 应为 `cfg : body`，在 ctx 中以键 cfg 为键，得到上下文 c1，以映射 c1 为配置，以 c1 的初始上下文为上下文，执行 body。返回 `output : aborted`，其中 output 是执行 body 的输出，比特 aborted 表示执行过程是否中止。
