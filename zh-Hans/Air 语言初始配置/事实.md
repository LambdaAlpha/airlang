# 事实

事实库是配置中的全局存储，用于记录函数调用的事实（输入与输出的映射关系）。可通过事实库进行正向查询和反向求解。

## .fact.put

类型：function

上下文：无关

input 应为 `func : input`，以 input 调用 func，将输入与输出记录到事实库。

## .fact.call

类型：function

上下文：无关

input 应为 `func : input`，从事实库中查询 func(input) 的输出。若存在则返回以单元格包裹的输出，否则返回单元。

## .fact.solve

类型：function

上下文：无关

input 应为 `func : output`，从事实库中反向求解使 func(input) = output 的输入。若存在则返回以单元格包裹的输入，否则返回单元。

## .fact.exist

类型：function

上下文：无关

input 应为 `func : input : output`，检查事实库中是否存在 func(input) = output 的事实，返回比特值。
