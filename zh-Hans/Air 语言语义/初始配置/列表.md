# 列表

## .list.get_length

类型：function

上下文：不变

输入：无关

ctx 应为列表，输出 ctx 的长度。

## .list.set

类型：function

上下文：可变

input 应为 `i : v`，ctx 应为列表，将 ctx 的第 `i` 项设置为 `v`，输出第 `i` 项原来的值。

## .list.set_many

类型：function

上下文：可变

input 应为 `i : vs`，`len` 为列表 `vs` 的长度，ctx 应为列表，将 ctx 从第 `i` 项到第 `i + len - 1` 项设置为 `vs`，输出被设置项原来的值的列表。

## .list.get

类型：function

上下文：不变

input 应为整数 `i`，ctx 应为列表，则输出 ctx 第 `i` 项的值

## .list.get_many

类型：function

上下文：不变

input 应为配对 `begin : end`，ctx 应为列表。

- 若 `begin` 为单元，则令 `begin` 为 `0`
- 若 `end` 为单元，则令 `end` 为 ctx 的长度
- 输出 ctx 第 `begin` 到第 `end -1` 项的值的列表

## .list.insert

类型：function

上下文：可变

input 应为 `i : v`，ctx 应为列表，在 ctx 的第 `i` 项后面插入 `v`。

## .list.insert_many

类型：function

上下文：可变

input 应为 `i : vs`，ctx 应为列表，在 ctx 的第 `i` 项后面插入列表 `vs` 所有元素。

## .list.remove

类型：function

上下文：可变

input 应为整数 `i`，ctx 应为列表，移除并输出 ctx 的第 `i` 项

## .list.remove_many

类型：function

上下文：可变

input 应为配对 `begin : end`，ctx 应为列表。

- 若 `begin` 为单元，则令 `begin` 为 `0`
- 若 `end` 为单元，则令 `end` 为 ctx 的长度
- 移除并输出 ctx 第 `begin` 到第 `end -1` 项的值的列表

## .list.push

类型：function

上下文：可变

ctx 应为列表，在 ctx 末尾插入 input。

## .list.push_many

类型：function

上下文：可变

ctx 应为列表，input 应为列表，在 ctx 末尾插入 input 的所有元素。

## .list.pop

类型：function

上下文：可变

ctx 应为列表，从 ctx 末尾移除 1 个元素并返回此元素。

## .list.pop_many

类型：function

上下文：可变

ctx 应为列表，从 ctx 末尾移除 input 个元素并返回此元素列表。

## .list.clear

类型：function

上下文：可变

输入：无关

ctx 应为列表，清空 ctx。
