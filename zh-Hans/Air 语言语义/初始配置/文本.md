# 文本

## .text.from_utf8

类型：function

上下文：无关

input 应为合法的 utf8 编码的字节，将 input 转化为文本。

## .text.into_utf8

类型：function

上下文：无关

input 应为文本，将 input 按 utf8 编码转化为字节。

## .text.get_length

类型：function

上下文：不变

输入：无关

ctx 应为文本，输出 ctx 的长度。

## .text.push

类型：function

上下文：可变

input 应为文本，ctx 应为文本，将 input 附加到 ctx 的后面。

## .text.join

类型：function

上下文：无关

input 应为文本列表，将 input 拼接成一个文本。
