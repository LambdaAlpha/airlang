# 文本

## .text.from_utf8

类型：function

上下文：无关

输入：相关

将合法的 utf8 编码的字节 input 转化为文本。

## .text.into_utf8

类型：function

上下文：无关

输入：相关

将文本 input 按 utf8 编码转化为字节。

## .text.get_length

类型：function

上下文：不变

输入：无关

输出文本 ctx 的长度。

## .text.push

类型：function

上下文：可变

输入：相关

将文本 input 附加到文本 ctx 的后面。

## .text.join

类型：function

上下文：无关

输入：相关

将文本列表 input 拼接成一个文本。
