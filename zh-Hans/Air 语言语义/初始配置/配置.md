# 配置

## .config.make

类型：function

上下文：无关

输入：相关

input 应为映射，使用 input 构造一个配置。

## .config.represent

类型：function

上下文：无关

输入：相关

input 应为配置，将 input 表示成一个映射。

## .config.exist

类型：function

上下文：无关

输入：相关

input 应为键，判断 cfg 中是否存在 input。

## .config.import

类型：function

上下文：无关

输入：相关

input 应为键，导入 cfg 中 input 的值。

## .config.export

类型：function

上下文：无关

输入：相关

input 应为 `key : value`，以 key 为键导出 value 到 cfg。

## .config.get_length

类型：function

上下文：不变

输入：无关

ctx 应为配置，获取 ctx 的长度。

## .config.with

类型：function

上下文：可变

输入：相关

input 应为 `map : body`，用 map 中的键值对覆盖 cfg，执行 body，得到 o，恢复 cfg，返回 o。

## .config.get_self

类型：function

上下文：无关

输入：无关

获取 cfg。

## .config.where

类型：function

上下文：可变

输入：相关

input 应为 `cfg : body`，在 ctx 中以键 cfg 为键，得到上下文 c1，以 c1 为配置，以 c1 的初始上下文为上下文，执行 body。
