# 值

## .value.any

类型：function

上下文：无关

输入：相关

若 input 为单元，则输出一个任意值。
若 input 为 `.syntax`，则输出一个语法值。
若 input 为键，代表一个类型（见 `type`），则输出对应类型的任意值。

此函数不对输出做任何保证，包括随机性。

## .value.get_type

上下文：不变

输入：无关

输出一个键，代表 ctx 的类型。

- 单元：`.unit`
- 比特：`.bit`
- 整数：`.integer`
- 小数：`.decimal`
- 字节：`.byte`
- 键：`.key`
- 文本：`.text`
- 单元格：`.cell`
- 配对：`.pair`
- 列表：`.list`
- 映射：`.map`
- 引用：`.quote`
- 调用：`.call`
- 链接：`.link`
- 配置：`.config`
- 函数：`.function`
- 其他拓展类型

## .value.equal

类型：function

上下文：不变

输入：相关

比较配对 input 左右两个值 `v1` 和 `v2` 是否相等。函数和链接是仅复制相等，其他内置类型是结构相等。
