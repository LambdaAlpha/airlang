# 链接

## .link.make

类型：function

上下文：无关

输入：相关

创建一个链接，其值为 input。

## .link.make_constant

类型：function

上下文：无关

输入：相关

创建一个不可变链接，其值为 input。

## .link.is_constant

类型：function

上下文：无关

输入：相关

input 应为链接，输出 input 是否不变。

## .link.is_available

类型：function

上下文：无关

输入：相关

input 应为链接，输出 input 当前是否可用。

## .link.get_id

类型：function

上下文：不变

输入：相关

input 应为链接，输出 input 的 id。id 相等的链接相等，反之也成立。

## .link.let

类型：function

上下文：无关

输入：相关

input 应为 `link : f : i`，以 link 的值为上下文，以 i 为输入调用 f。

## .link.let.bind

类型：function

上下文：无关

输入：相关

input 应为函数，输出一个函数 `g`，使得 `ctx g input` 等价于 `ctx link.let g : input`。

大多数上下文读写函数都导出了绑定函数，绑定函数的键为原函数的键 + `.link.let`。
