# Key

The key type represents a character sequence over a finite character set.

Graphic characters: all graphic characters in the ASCII range, from ` ` (inclusive) to `~` (inclusive). Namely letters (`a-zA-Z`), digits (`0-9`), punctuation (`` ()[]{}<>\|/'"`^*+=-~_.,:;!?@#$%& ``), and space (` `).

Key: a sequence of graphic characters.

Keys are used as keys for binding values in a context.
