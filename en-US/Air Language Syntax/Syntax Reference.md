# Syntax Reference

## Structure

- `()`: scope, aids parsing
- `[]`: list
- `{}`: map
- `<^>v`: associativity
- `-|/\`: directional
- ``'"`^``: high, character, text
- `*+=-~`: medium
- `_`: low
- `.,:;!?`: dot, prefix/infix
- `@#$%&`: complex characters
- `_.:`, `_-=`, `.-=`: 0, 1, 2
- `bdpq`: directional

## Single Symbols

- `\`: (unused)
- `|`: (unused)
- `/`: (unused)
- `'`: key delimiter
- `"`: text delimiter
- `` ` ``: (unused)
- `^`: (unused)
- `~`: (unused)
- `-`: integer and number negation
- `+`: integer and number positive, text line split
- `=`: (unused)
- `_`: nullary, quote prefix, call, key prefix (quote), key and text connector
- `.`: unit, cell prefix, key prefix (cell), text line-feed
- `,`: list and map separator
- `:`: binary, pair, text line-feed
- `;`: (unused)
- `!`: comment prefix
- `?`: solve
- `@`: (unused)
- `#`: (list, map) lexical mode
- `$`: (unused)
- `%`: (unused)
- `&`: (unused)
- `*`: (unused)

## Symbol Conventions

- `= :=`: assignment
- `< <= == > >=`: order comparison
- `== === != !== /= /==`: equality comparison
- `+ - * / %`: arithmetic
- `& && | || ! ~ ^ << >>`: logical operations
- `+= -= *= /= %= &= |= ~= ^=`: compound assignment
