# Initial Configuration

The initial configuration contains many values, each identified by a unique key.

Document conventions:

- In function documentation, unless stated otherwise:
  - Functions are primitive by default
  - `input` refers to the input, `ctx` refers to the call-time context, `cfg` refers to the current config
  - When input, context, or config does not meet expectations, execution aborts

## Initial Context

Keyed by `.prelude`, the value is a map used to initialize the context.
